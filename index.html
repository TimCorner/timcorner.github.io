Comment fonctionne l'Espace Admin ?

1. Faut-il toucher au code pour modifier la liste ?
Non ! Cliquez sur le bouton « Admin » en haut à droite (code PIN : 1234). Vous pouvez ajouter, éditer ou supprimer un cadeau, ses photos et ses marchands via un simple formulaire.

2. Comment les réservations et ajouts sont-ils sauvegardés ?
Cette page est connectée en temps réel à Firebase Firestore (base de données cloud gratuite de Google). Dès qu'un proche réserve un cadeau avec son prénom ou que vous ajoutez un article, tous les visiteurs voient la mise à jour instantanément.

3. Pour votre propre dépôt GitHub Pages :
Si vous copiez ce fichier sur votre compte GitHub Pages personnel, il vous suffit de créer un projet gratuit sur console.firebase.google.com (2 minutes) et de coller votre bloc firebaseConfig dans la variable prévue en bas du fichier.
